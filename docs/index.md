## ==Что это?==
WebPartyTime - ==платформа для создания и проведения интерактивных онлайн-презентаций==.

!!! note ""
    Презентации с голосованием или необычным форматом переключения слайдов, 
    игры-викторины, генераторы идей - всё это можно создать средствами WebPartyTime.

==Цель проекта== - предоставить удобный и гибкий набор инструментов для создания многопользовательского опыта в формате "ведущий-участники".


При этом ==платформа независима от внешних сервисов== и при необходимости ==может изменяться и запускаться полностью локально==.

## ==Функции==
* Проведение ==интерактивных многопользовательских презентаций== прямо в браузере
* ==Гибкая система сценариев== для разработки собственных форматов презентаций
* ==Модульная архитектура== для обеспечения расширяемости проекта разработчиками
