## ==Регистрация==
* Нужна для загрузки и запуска ==собственных сценариев==.
* Требуется для присоединения к комнатам, ==если организатор не разрешил анонимные подключения==.


==Чтобы зарегистрироваться==, перейдите на главную страницу проекта и нажмите на круг со стрелочкой вправо, чтобы открыть форму регистрации. Введите требуемые поля и нажмите =="Начать"==.

==Если у вас уже есть аккаунт==, воспользуйтесь опцией =="У меня уже есть аккаунт"==, расположенной ниже кнопки перехода к регистрации. Заполните поля формы данными, использованными при регистрации.

==Если вы хотите продолжить анонимно==, выберите =="Продолжить без регистрации"==

!!!note ""
    При успешном входе в систему одним из перечисленных выше способов вы будете автоматически перенаправлены на основной экран WebPartyTime.

Перед продолжением убедитесь, что вас устраивает ваш ==псевдоним== и ==изображение профиля== (сверху справа страницы):


* Изображение определяется ==введённым псевдонимом== (случайно).
* При необходимости ==вы можете изменить свой псевдоним== в том же поле, где он отображается, но ==только вне подключения к комнате==.
