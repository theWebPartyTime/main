# Frontend
## ==Основы==
До организации и подключения к комнате устанавливается подключение к серверу ==Centrifuge==, но при этом работа со страницей достаточно стандартна.


Когда пользователь попадает в онлайн-комнату в любом режиме, ==почти все взаимодействия осуществляются через веб-сокет==.


Во время работы ==PartyFlow== поля ==layout==, ==input==, ==vote==, ==overviewer== передаются соответствующим пользователям, и задачей фронтенда становится ==парсинг этих полей== и ==отрисовка их пользователю==.

##  ==Структура файлов==
==./public/== - содержит шрифт проекта и его favicon


==./src/== - исходный код и ресурсы приложения

- ==assets/== - используемые проектом изображения
- ==components/== - переиспользуемые приложением элементы разметки и интерфейса
- ==pages/== - разметка, стили и код экранов приложения
- ==routes/== - определение путей приложения
- ==stores/== - глобальные хранилища для переменных приложения
- ==App.vue, main.ts== - корневые файлы веб-приложения
##  ==Пути==
==/== - ==Страница онбординга==
(если пользователь не выбрал продолжить без регистрации или не создал аккаунт) либо ==основная страница==, где можно создавать комнаты и подключаться к ним

==/auth== - ==Страница авторизации==, где пользователь может зарегистрироваться, войти в существующий аккаунт или продолжить анонимно


==/game -== ==Отображение текущей презентации== (и для ведущего, и для участников)
